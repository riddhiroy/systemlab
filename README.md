# SystemLab

Interactive system design learning and simulation playground.

## Run locally

```bash
npm install
npm run dev
```

## Stack
- React + TypeScript + Vite
- React Flow (`@xyflow/react`)
- Lucide icons

## MVP features
- Visual node-based architecture editor
- Component palette and editable node settings
- Traffic and failure simulation with transparent assumptions
- Learning roadmap and interview challenges
- Local browser save/load

The simulation is an educational model, not a production capacity planner. Supabase authentication, cloud persistence, billing and AI feedback are planned follow-on work.
